# 📝 Notes App

A soft, cute notes app — create, edit, delete, and search your notes, all styled like little pastel sticky notes.

## Skills learned

- CRUD operations (Create, Read, Update, Delete)
- Local storage
- UI design

## Features

- ✏️ Create notes
- 🖊️ Edit notes
- 🗑️ Delete notes
- 🔍 Search notes
- 🎨 Pick a color for each note (pink, lavender, mint, peach)
- 💾 Notes are saved to your browser's local storage, so they're still there when you come back

## Tech

Plain HTML, CSS, and JavaScript — no frameworks or build tools needed. Just open `index.html` in a browser.

## Running it

```bash
git clone https://github.com/<Hitch469>/Notes-app.git
cd notes-pad
```

Then just open `index.html` in your browser — no install, no server needed.

Or, to serve it locally:

```bash
python -m http.server 5500
```

and visit `http://localhost:5500`.
